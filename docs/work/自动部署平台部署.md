# 自动部署平台部署

以 root 用户直接部署

# 准备 conda 环境（方便以后环境迁移）

1. 下载 conda `wget https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/Miniconda3-latest-Linux-x86_64.sh --no-check-certificate`
2. 安装 <code>chmod +x Miniconda3-latest-Linux-x86_64.sh && bash Miniconda3-latest-Linux-x86_64.sh</code>
3. 更新一下环境 `source /root/.bashrc`
4. 修改 conda 为清华源 <code>conda config --set show_channel_urls yes && vim ~/.condarc</code>

```yaml
channels:
```

5. 清理默认源缓存 `conda clean -i`
6. 运行命令创建 python3.6 的虚拟环境 `conda create -n auto_deploy python==3.6`
7. 创建完成后在环境变量里指定默认虚拟环境`vim ~/.bashrc`，写入命令到最后 `conda activate auto_deploy`
8. 重新加载下环境变量 `source ~/.bashrc`

# 升级 yum

1. 先备份一下源 `mv centos7.6.repo centos7.6.repo.backup`
2. 下载淘宝源`wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo`
3. 清除缓存并且升级 `yum clean all && yum makecache && yum update -y`

# 开始安装依赖的 Python 环境

1. 在可运行的宿主机器上运行 `pip3 freeze > requirement.txt` 获取环境变量版本
2. 复制 requirement.txt 到新的机器上，先安装一下 pbr `pip install pbr -i https://pypi.tuna.tsinghua.edu.cn/simple`然后再安装全部依赖包 `pip install -r requirement.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`
3. 运行 `pip freeze > t1.txt`比较一下和原来导出版本的异同，除了 pbr 其它都应该一致

# 安装 screen 升级 gcc

1. `yum -y install screen`
2. 查看gcc版本，如果小于5.3 则需要升级，否则需要安装：`gcc -v`
3. 升级一下 gcc `yum -y install centos-release-scl devtoolset-9-gcc devtoolset-9-gcc-c++ devtoolset-9-binutils`
4. 临时启用 gcc9 `scl enable devtoolset-9 bash` 永久启用`echo "source /opt/rh/devtoolset-9/enable" >> /etc/profile`

# 安装 supervisor

1. 首先安装 epel 源 `yum -y install epel-release`
2. yum 安装 supervisor `yum -y install supervisor`

# 安装 Redis

1. 下载 redis `wget https://download.redis.io/releases/redis-6.0.7.tar.gz`
2. 解压并编译 `tar -xf redis-6.0.7.tar.gz && make && make install PREFIX=/opt/softs/redis6.0.7`
3. 尝试使用配置文件启动 `./redis-server ./redis.conf`这里只是尝试启动，后面会统一编排

# 安装 MySQL

1. 首先删除 centos 自带的 mariadb <code>rpm -e mariadb-libs --nodeps</code>
2. 安装依赖环境 <code>yum -y install libaio autoconf</code>
3. 下载 mysql <code>wget https://cdn.mysql.com/archives/mysql-5.6/mysql-5.6.26-linux-glibc2.5-x86_64.tar.gz</code>
4. 解压文件后重新命名并分配用户组 <code>tar -xf mysql-5.7.31-linux-glibc2.12-x86_64.tar.gz && mv mysql-5.7.31-linux-glibc2.12-x86_64.tar.gz mysql5.7.31 && chown -R mysql:mysql mysql5.7.31</code>
5. 查看系统是否有 mysql 用户和用户组 <code>cat /etc/passwd|grep mysql</code> <code>cat /etc/group|grep mysql</code>如果存在需要删除后重新创建 `userdel -r mysql`
6. 创建 mysql 用户和用户组 <code>groupadd mysql && useradd -r -g mysql mysql</code>
7. 设置mysql用户为非登陆用户 <code>usermod -s /sbin/nologin mysql</code>
8. 创建对应的 log 目录
9. 新建配置文件

# 安装 Nginx

1. 首先去下载 Nginx `http://nginx.org/download/nginx-1.8.1.tar.gz`
2. 安装依赖项 <code>yum install -y openssl* libncurses-dev</code>如果是 debian11 修改命令<code>apt-get install -y openssl libssl-dev libncurses-dev zlib1g.dev</code>
3. 解压并配置模块和安装路径 <code>tar -xf nginx-1.8.1.tar.gz && cd nginx-1.8.1 && ./configure --prefix=/opt/softs/nginx-1.8.1 --with-http_stub_status_module --with-http_ssl_module --with-http_gzip_static_module</code>
4. 去除编译警告视为错误的 Makefile 配置 `vim /opt/packages/nginx-1.8.1/objs/Makefile`去除 `-Werror`

![1679539355359-76d81fc0-0995-4479-8001-4cebaf7e432f.png](../images/work/自动部署平台部署/1.png)

5. 开始安装 `make && make install`

9. 修改复制过来的 `apprun.sh`文件，重新定义要执行的命令路径和配置文件路径

```bash
#!/usr/bin/bash

WORK_DIR=/opt/softs/auto_deploy/autotwo_py3
CONF_DIR=/opt/softs/auto_deploy/conf
REDIS_DIR=/opt/softs/redis6.0.7/bin
NGINX_DIR=/opt/softs/nginx-1.8.1/sbin

# switch to work directory
cd $WORK_DIR

# mysql start
service start mysql
sleep 5

# redis start
$REDIS_DIR/redis-server $CONF_DIR/redis.conf

# supervisor start
/usr/bin/supervisord -c $CONF_DIR/supervisord.conf

# nginx start
$NGINX_DIR/nginx -c $CONF_DIR/nginx.conf
```

10. 修改复制过来的 `nginx.conf`文件主要修改日志文件路径和资源文件路径
11. 顺便把源机器上的 nginx 中 ssl 目录下的证书也复制过来，或者自己用工具生成新的也行
12. 修改复制过来的 `redis.conf`主要修改其中的主路径
13. 修改复制过来的 `uwsgi.xml`主要也是修改路径
14. 修改复制过来的 `supervisord.conf`其中大部分的路径都要进行修改
15. 卸载安装的 <code>uwsgi``pip uninstall uwsgi</code>
16. 安装 xml 解析模块 <code>yum install -y libxml*</code>重新安装 <code>pip install uwsgi -i https://pypi.tuna.tsinghua.edu.cn/simple</code>
